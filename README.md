# Portfolio V3 — The Modernist

> Swiss editorial aesthetic · Cream/white palette · DM Serif Display · Accordion case studies

## Design

**The Modernist** is a clean, Swiss-editorial-inspired portfolio design. It emphasises structure, whitespace, and typographic hierarchy. Projects expand as accordion panels with image + outcome details on click.

## Stack

- React + TypeScript
- Motion (animation)
- Lucide React (icons)
- Google Fonts: DM Serif Display + DM Sans

## Getting Started

```bash
npm install
npm run dev
```
