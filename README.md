# Portfolio V3 — The Bold

> Full-screen dark gradient hero · Space Grotesk · Mouse-parallax effects · Scrolling ticker band

## Design

**The Bold** is a high-energy, dark-mode portfolio design. It features a full-screen hero with a cyan–purple gradient name display, interactive mouse-tracking spotlight, animated ticker band, expertise cards, and split-layout project showcases.

## Stack

- React + TypeScript
- Motion (animation)
- Lucide React (icons)
- Google Fonts: Space Grotesk

## Getting Started

```bash
npm install
npm run dev
```
